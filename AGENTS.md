# Learn Explorer

Thai RIASEC interest profiler for high-school students, plus admin dashboard. AdonisJS 7 + Inertia React + Lucid (PostgreSQL) + Japa. Scoring and UI reference: `../learn_explorer_prototype/src/interest_profiler`. Design brief: `concepts_brief.md`.

## Read the guide before you build

Every backend or frontend change starts in `ai-knowledges/`. Open the index, read only the files your task needs, then follow the guide's pattern. When the guide and your habit differ, the guide wins.

| Task | Start here |
| --- | --- |
| Routes, controllers, middleware, auth, Inertia pages, transformers, validators, logger, health, ace commands | `ai-knowledges/adonisjs7/index.md` |
| Migrations, columns, indexes, constraints, models, queries, transactions | `ai-knowledges/lucid/index.md`, then `ai-knowledges/adonisjs7/lucid_sql_orm.md` |
| Tests, suites, DB reset between tests | `ai-knowledges/adonisjs7/test.md`, `ai-knowledges/adonisjs7/reset-state-between-test.md`, `ai-knowledges/japa/index.md` |
| LLM features (not used yet) | `ai-knowledges/openrouter/index.md`, `ai-knowledges/vercel_ai/`, `ai-knowledges/vercel_eve/index.md` |
| Spreadsheet import/export | `ai-knowledges/xlsx/index.md` |

## The AdonisJS Way

**Generate, then edit.** Create every file with its `node ace make:*` command so names, timestamps and locations are right (`node ace list` shows them all):

| Need | Command |
| --- | --- |
| Table change | `node ace make:migration <name> --create=<table>` or `--alter=<table>` |
| Model | `node ace make:model <Name>` |
| Controller | `node ace make:controller <name>` |
| Validator | `node ace make:validator <name>` |
| Transformer (Inertia props) | `node ace make:transformer <name>` |
| Middleware | `node ace make:middleware <name>` |
| Service | `node ace make:service <name>` |
| Ace command | `node ace make:command <name>` |
| Test | `node ace make:test <path> --suite=<unit\|functional\|browser>` |

**Schema lives in migrations.** Express tables, indexes, foreign keys (`onDelete('CASCADE')`), and checks (`checkIn`, `checkBetween`) with the Lucid table builder. Reach for `this.schema.raw()` only for DDL the builder cannot express, and note why in the migration.

**Models stay thin.** `database/schema.ts` is generated by `node ace migration:run`; models extend it and add only relationships, hooks, and domain methods. Change a column type through a new migration, or through `database/schema_rules.ts` for TS types (role unions, typed JSON).

**Data access goes through Lucid.** Use model methods (`create`, `firstOrCreate`, `updateOrCreate`, `merge().save()`), the query builder, and `db.transaction`. Use `db.raw` only inside a builder call for an expression Lucid has no method for (e.g. `date_bin`).

**Frontend receives JSON.** Pass data to pages through transformers; frontend code imports types from `.adonisjs/client`, never backend code.

## Data rules

Student data belongs to minors under Thai PDPA [DP-001]. Log attempt UUIDs only, never phone, email, `code`, or free text.
